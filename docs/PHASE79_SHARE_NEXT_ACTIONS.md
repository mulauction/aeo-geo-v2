# Phase 79 — Share Next Actions 설계 (진단/디자인)

## 목적
Share 화면을 본 사용자가 다음 행동을 자연스럽게 하게 만들기(강매 금지)

---

## 다음 행동(Next Actions) 4종 정의

### 1) PDF 저장(인쇄)
- **사용자 의도**: 결과를 문서로 남기고 내부 공유/보고/보관에 쓰고 싶다.
- **최적 상황**: 팀 공유(메신저/이메일)보다 “문서 첨부/결재/보관” 흐름이 필요할 때.
- **사용할 가능성이 높은 기존 UI**: Share 화면의 `PDF로 내보내기` 버튼(인쇄/저장 흐름).

### 2) 링크 복사(공유)
- **사용자 의도**: 팀원/고객에게 빠르게 공유하고, 같은 화면을 다시 열 수 있게 하고 싶다.
- **최적 상황**: 실시간 공유(메신저)나 “나중에 다시 보기(재방문)”가 목적일 때.
- **사용할 가능성이 높은 기존 UI**: Share 화면의 `재열람 링크 복사` 버튼(리포트 재열람 링크 고정 영역).

### 3) 다시 분석(다른 URL/상품)
- **사용자 의도**: 대상(URL/상품)을 바꾸거나, 최신 상태로 다시 측정/생성하고 싶다.
- **최적 상황**: Share에서 리포트를 열 수 없거나(Non-OK), 다른 대상에 적용해 보고 싶을 때.
- **사용할 가능성이 높은 기존 UI**: Non-OK 상태에서 제공되는 “다시 분석”으로 이어지는 기존 흐름(버튼/링크 동작은 Phase 77 정책 그대로).

### 4) 개선/Pro 업그레이드(필요 시)
- **사용자 의도**: 결과를 바탕으로 개선 작업을 확장하거나, 더 많은 기능/워크플로우가 필요하다.
- **최적 상황**: (반복 사용/팀 공유/보고 자동화 등) “지금 당장” 필요가 생겼을 때만.
- **사용할 가능성이 높은 기존 UI**: Share 화면의 기존 Pro/업그레이드 관련 영역(버튼/모달 등 기존 UI만 활용; 신규 CTA 금지).

---

## 상태 기반 우선순위(상태당 1~2개만 강조)

### OK (정상 리포트)
- **우선 강조**: (1) 링크 복사, (2) PDF 저장
- **중심 가치**: “공유/저장”

### Non-OK (리포트 없음/만료/다른기기/실패/잘못된 링크)
- **우선 강조**: (1) 다시 분석, (2) 최근 리포트 열기
- **중심 가치**: “복구”
- **불변 조건(중요)**: EXPIRED/OTHER_DEVICE/NO_REPORT/FETCH_FAIL/INVALID_ID 등 Non-OK 세부 상태에서도 **Phase 77 CTA 정책(버튼/순서/동작)은 그대로 유지**한다. (신규 버튼 추가/재배치/행동 변경 금지)

---

## “강매 금지” 원칙
- **Pro/개선은 보조 옵션**: “필요할 때만” 선택지로 언급하고, 사용자를 압박하지 않는다.
- **톤 가이드**:
  - 짧고 명확하게(1~2줄)
  - 사실 기반(과장/성과 보장 문구 금지)
  - 압박/협박/한정판매/공포 조장 금지
  - 선택권 존중(“~할 수 있어요/편합니다/필요하면”)

---

## Phase 79-1 (UI-only) 구현 메모 (지금은 코드 변경 없음)

### 추가 위치(1~2줄, 화면용 카피)
- **OK**: 헤더/요약 “위” 1줄 안내 영역 근처에 1줄(또는 2줄 이내)로 추가
- **Non-OK**: Non-OK 안내박스 상단 1줄 안내 영역 근처에 1줄(또는 2줄 이내)로 추가

### SSOT/Print 영향 0 원칙(필수)
- 화면(Screen)에서만 보이는 **카피 영역**에만 추가한다.
- Print SSOT/CSS/키워드/가드에는 **손대지 않는다**. (print 관련 코드/SSOT 키워드 변경 금지)
- Phase 77 CTA 정책과 충돌 금지: **새 버튼 제안/CTA 재배치/동작 변경 요청 금지**.

### OK 카피 후보 (1~2줄, 비세일즈)
- “팀 공유는 링크 복사, 내부 보고는 PDF 저장이 편합니다.”
- “공유는 링크 복사, 보관은 PDF 저장을 사용해보세요.”
- “필요하면 링크를 복사해 공유하거나 PDF로 저장해 두세요.”

### Non-OK 카피 후보 (1~2줄, 비세일즈)
- “이 링크는 이 브라우저에 리포트가 없어 열 수 없습니다 → 최근 리포트 열기 / 다시 분석”
- “리포트를 열 수 없습니다. 아래에서 다시 분석하거나, 이 브라우저의 최근 리포트를 확인해보세요.”
- “복구 방법: 다시 분석(새로 생성) 또는 최근 리포트 열기(이 브라우저).”

---

## 체크(문서 자체 점검)
- 신규 버튼/CTA 재배치/행동 변경을 요구하지 않는다.
- Phase 77 CTA 정책/Print SSOT/저장/telemetry/상태판정 로직에 영향이 없도록 “카피/배치(화면용)”로만 표현한다.
